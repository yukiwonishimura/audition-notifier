# 応募者プロフィールと評価基準

> このファイルは検索AIと評価AIの両方が読み込みます。内容を書き換えれば挙動が変わります。

## 応募者プロフィール

- 男性、30代
- 俳優（東京在住）
- 出演を希望するジャンル: 映画 / ドラマ / 舞台 / CM / MV / Webドラマ / 広告
- 目的: 俳優としての実績と認知度を高めること
- 事務所所属状況・語学・特技などの追記があればここに書く

## 探す案件

俳優（特に30代男性が応募可能な役）のオーディション・キャスト募集。
映画・ドラマ・舞台・CM・MV・Webコンテンツなどの出演者募集ページ。

### 対象外の役（これらは収集・通知しない）

- アンサンブル、アンサンブルキャスト
- ダンサー、ダンス経験者募集、バックダンサー
- 上記が主目的の募集は、たとえ他条件が合っても対象外とする（研究段階の配列に含めない）。
  セリフのある名前つきの役があり、アンサンブル/ダンサーはその一部に過ぎない場合は対象に含めてよい。

### 検索キーワード（起点。AIは自律的に追加してよい）

- 俳優 オーディション / 男性俳優 オーディション / 30代 男性 キャスト
- 俳優 募集 / 映画 キャスト募集 / ドラマ キャスト募集
- 舞台 出演者募集 / CM オーディション / MV 出演者募集
- Webドラマ キャスト / 短編映画 キャスト

X（旧Twitter）・Threads・一般Web検索・オーディション専門サイト・制作会社の公式サイトを
可能な範囲で横断する。SNSで見つけた場合は、可能なら元の募集元・公式募集ページまで遡って確認する。

## 評価ルーブリック（100点満点）

| 観点 | 配点 |
| --- | --- |
| 作品規模 | 20 |
| 制作会社・監督などの信頼性 | 20 |
| キャリアへのインパクト | 20 |
| 役の魅力度 | 15 |
| 自分との適性（年齢・性別・条件一致） | 15 |
| 応募条件・応募しやすさ | 10 |

### ランク

- 90点以上: `S+`
- 80〜89点: `S`
- 70〜79点: `A`
- 60〜69点: `B`
- 59点以下: `reject`（通知不要）

原則として `S+` / `S` / `A` だけを通知する。

## 除外する怪しい案件

以下は原則 `reject` かつ `suspicious: true` とする。

- 高額な登録料・レッスン契約・オーディション参加費
- 不自然な金銭要求
- 制作会社・主催者が不明
- 募集内容が極端に曖昧
- 不自然な個人情報の要求
- 「必ず売れる」など過度な勧誘
- MLM・情報商材の可能性
- その他、悪質な募集の可能性があるもの
